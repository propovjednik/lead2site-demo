# lead2site demos

Live demos of website drafts generated with **lead2site**, an agent plugin that turns local businesses into
one-of-a-kind animated websites.

**[Open the demos](https://propovjednik.github.io/lead2site-demo/)**

- Saltglaze Homes, an estate agent: a gable rises over the street, then a window opens into a living room.
- Kestrel Motors, a car dealer: the hero car falls down the page and lands in the next scene.

Both businesses, their places and all their details are fictional. Photos from [Unsplash](https://unsplash.com).
This repository only holds the built pages.
